# Crédits des captures d'écran

Les captures de ce dossier montrent la vraie interface de MyPhotos (0.1.0 ; 0.2.0 pour l'écran « Doublons » ; 0.3.0 pour la fenêtre), essayée sur un dossier de photos publiques. Toutes ces photos viennent de Wikimedia Commons, où leurs auteurs les ont versées dans le domaine public (licence [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/deed.fr)). Aucune photo personnelle n'y figure.

Ces photos ont été téléchargées en 1 280 pixels de large (vignettes de Wikimedia Commons), sans autre retouche. La licence CC0 n'impose aucune mention ; nous citons quand même les auteurs, par courtoisie.

Pour `doublons.png`, des doublons ont été fabriqués à partir de ces photos, comme la licence CC0 le permet : des copies exactes (« chien-labrador - Copie.jpg », « chien-blanc (2).jpg »), une version réduite et recompressée comme par une messagerie (« IMG-20190721-WA0004.jpg »), une version plus petite (« chien-noir-petit.jpg ») et, dans la rubrique repliée des rafales, trois cadres décalés de « Dog in Chacachacare ». Les noms de dossiers affichés sont ceux du dossier d'essai, vu par MyPhotos sous une lettre de lecteur à part : aucun chemin personnel.

La capture `fenetre.png` a été prise avec `MyPhotos.exe` 0.3.0, sur un bureau Windows à part, par la fonction PrintWindow de Windows appliquée à la seule fenêtre de MyPhotos (cadre et barre de titre compris) : aucun autre programme, aucun chemin de dossier n'y apparaît.

La capture `premier-lancement.png` décrit le PC d'essai (processeur Ryzen 5 5600X, carte Radeon RX 6600 XT), celui sur lequel les débits des moteurs ont été mesurés.
